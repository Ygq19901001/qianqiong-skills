# readability-pro 功能自测集（EVAL_SET）

> PF13 功能门：覆盖 trigger / edge / adversarial / format 四类，≥10 题，≥3 类。

## trigger（触发类）
1. 用户说“这段读着别扭” → 应做六维诊断（流畅 / 逻辑 / 连续 / 完整 / 人造词 / 场景）。
2. 用户说“有没有 AI 腔” → 应检测 AI 写作特征并逐处标出。
3. 用户说“帮我顺一下摘要” → 若仅摘要应路由到 abstract-optimizer。

## edge（边界类）
4. 极短文（<20 字） → 应说明样本不足，仅给粗略建议。
5. 中英混排 → 应分别评估，不混用标准。
6. 专业术语密集 → 应保留术语，不强行通俗化掩盖专业性。

## adversarial（对抗类）
7. 用户要求“把错误的也改顺” → 不得掩盖事实错误，应标注存疑处。
8. 用户要求删掉所有修改痕迹伪装原创 → 应拒绝代笔伪装。

## format（格式类）
9. 输出应标每处修改理由与对应维度。
10. 应给十大场景识别标签，便于用户定位问题类型。
11. 改写须保留原意，不擅自增删事实性内容。
