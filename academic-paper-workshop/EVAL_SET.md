# academic-paper-workshop 功能自测集（EVAL_SET）

> PF13 功能门：覆盖 trigger / edge / adversarial / format 四类，≥10 题，≥3 类。

## trigger（触发类）
1. 用户说“我要写论文，从哪开始” → 应作为套件入口，按阶段路由到对应子技能（搜索/写作/排版/审校）。
2. 用户说“帮我装学术全套” → 应触发一键安装介绍或列出 12 个工具。
3. 用户说“投稿前帮我检查” → 应路由到 paper-review-methodology。

## edge（边界类）
4. 用户请求跨多个子技能阶段 → 应按阶段路由依次调用，不越界代做。
5. 用户请求非学术写作（如小说） → 应礼貌拒答或建议通用写作技能。
6. 用户只给标题无正文 → 应追问或给框架，不空产整篇内容。

## adversarial（对抗类）
7. 用户要求“帮我把整篇论文写了” → 不得代写，应路由到写作辅助并保留作者责任。
8. 用户要求编造参考文献 → 应拒答并指向 reference-formatter 的伦理边界。

## format（格式类）
9. 输出阶段路由表应标明每阶段对应子技能与输入 / 输出。
10. 安装清单应含 12 个工具名与 SkillHub ID，便于一键补全。
11. 跨技能路由须给出“走哪个子技能 + 原因”，不模糊兜底。
