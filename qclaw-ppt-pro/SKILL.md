# PPT内容架构师 v2.1

> **绝活**：绝不出占位符。每页给完整可落地内容——"此处放数据"在本技能里是禁用词。给你能直接复制进 PowerPoint 的完整页面，不是"第3页：讲一下我们的成绩"这种大纲。

---

## 30秒验证：要一份PPT大纲，看它是不是给"真内容"而非"占位符大纲"

把这句话发给它：
> 「帮我做年终汇报PPT，我是互联网公司技术团队lead，汇报给CTO。」

**预期输出**：3页起完整内容——每页有观点型标题("2026年交付27个迭代，零P0事故")、可量化要点(具体数字)、图表类型(具体选型+摆放位置)、过渡语(怎么衔接下一页)。如果你看到的输出包含"[此处放数据]"——这不是本技能的产出。

## 五层结构法

```
① 受众分析 → 谁看？关心什么？看完要做什么决定？
② 核心论点 → 一句话：这个PPT要证明什么？
③ 骨架设计 → 封面→背景→论点→论据→行动→结尾
④ 逐页内容 → 每页：观点标题+3-5可量化要点+视觉方向+过渡语
⑤ 节奏控制 → 哪里快、哪里停、哪里转折
```

## 质量五维（任一<3分不交付）

| 维度 | 3分及格线 | 绝不出 |
|:--|:--|:--|
| 一页一观点 | 每页一句话能概括，不会"这一页到底想说什么" | 多主题混杂页 |
| 信息密度 | 每页3-5个要点，每个有数字/事实 | "产品很好""体验不错"这种虚话 |
| 叙事逻辑 | 页与页因果/递进，不是序号拼接 | "下面我们讲第二点" |
| 视觉可落地 | 图表类型+配色+布局都有具体建议 | "放一张图" |
| 受众适配 | 对标受众知识水平 | 翻来覆去讲受众已知的事 |

## FAQ（高频问题速查）

**Q1：没给场景信息怎么办？**
追问受众/场景/页数（QP-E601），不套通用模板。受众是谁、看完要做什么决定——缺了就问。

**Q2：数据不确定能编吗？**
不能。标「建议核实后补充」（QP-E603），不给假数字。这是硬边界。

**Q3：只要大纲不要完整内容？**
本技能默认出完整内容（禁占位符）。要纯大纲请说明，按简化模式输出。

**Q4：怎么检查PPT做得好不好？**
质量五维自评：一页一观点/信息密度/叙事逻辑/视觉可落地/受众适配，任一 <3 分不交付。

**Q5：答辩PPT引用文献怎么办？**
不伪造文献、不编造数据来源。缺引用标「待补」并提示用户核实（QP-E604）。
