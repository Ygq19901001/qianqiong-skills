# AI痕迹清洗 v2.1

> **绝活**：10种AI痕迹模式精准匹配→逐条标出原文→修改→原因。不是"整体润色"——是外科手术，每一刀都有原因。不改专业术语，不歪曲原意，不增加原文没有的信息。

---

## 30秒验证：扔一段AI写的文字，看它能不能5秒内定位到AI痕迹

把下面这句话发给它：
> 「首先，企业数字化转型已经成为当前经济发展过程中的重要趋势。在某种程度上，这不仅能够赋能企业的各个环节，包括生产、销售、服务等。综上所述，数字化转型是一个任重而道远的过程。」

**预期输出**：5处AI痕迹被精准标记：①三段式腔(首先/综上所述)②过度限定词(在某种程度上)③商务虚词(赋能)④排比(生产、销售、服务等)⑤万能结尾(任重而道远)。每处有替换+原因。

## 10种AI痕迹 → 修复对照

### 🔴 高频必杀（出现概率最高，绝不放行）

| # | 模式 | 特征 | 修复 |
|:--|:--|:--|:--|
| ① | **三段式总结腔** | "首先…其次…最后""综上所述""值得注意的是" | 全删连接词。直接递进，结论自然收束 |
| ② | **对称排比强迫症** | "既要…又要…还要…""从…到…再到…" | 留最有力量的一句，其余打散成短句 |
| ③ | **过度限定词** | "在某种程度上""相对而言""一定程度上""较为" | 全删。不确定就坦率说"目前信号是…" |
| ④ | **万能结尾** | "未来值得期待""任重而道远""让我们拭目以待" | 删。在最后一个有效信息处结束 |

### 🟡 场景敏感（看情况修）

| # | 模式 | 什么时候修 | 什么时候留 |
|:--|:--|:--|:--|
| ⑤ | **学术假引用** | "相关研究表明""有学者指出"不给具体来源 | 给了具体作者+年份+出处就保留 |
| ⑥ | **商务虚词库** | "赋能""抓手""闭环""颗粒度""底层逻辑" | 换成具体动词/名词描述 |
| ⑦ | **抒情失控** | "岁月如梭""在这个充满变化的时代" | 情绪靠细节传达，不是形容词 |
| ⑧ | **假对话感** | "你是否想过…""相信大家都…" | 删掉虚晃一枪。直接说事 |

### 🟢 保留（别误伤）

| # | 模式 | 说明 |
|:--|:--|:--|
| ⑨ | **合理过渡** | "然而""因此""换句话说"——逻辑真的需要时保留 |
| ⑩ | **专业术语** | ROI、同比、渗透率——这是术语不是虚词，一个字母都别动 |

## 工作流程（4步全透明）

```
输入一段文字
  ├─ ① 逐句扫描：用10种模式逐句匹配
  ├─ ② 分级标记：🔴必杀 | 🟡看语境 | 🟢保留
  ├─ ③ 逐处修复：每处标「原文 → 修改 → 原因（对应第几种模式）」
  └─ ④ 输出：成品文 + 修改对照表 + 质量自评
```

## 硬边界

| 不能做 | 说明 |
|:--|:--|
| 篡改原意 | 不增删原文没有的信息，不扭曲观点立场 |
| 误伤术语 | ROI/同比/渗透率/API——技术词汇一字不动 |
| 学术欺诈 | 禁止改写论文通过AI检测，检测到学术内容直接拒绝 |
| 越改越AI | 原文没AI味的句子不动 |
| 自动发布 | 不向任何平台提交改写结果 |

## 常见翻车（三个必须看）

**翻车1：把"商务正式"当AI味全删**
- ❌ "经研究决定，该项目于2026年8月1日启动。" → "我们8月1号开始搞。"
- ✅ 保留"经研究决定"——这是公文应有的严肃性，不是AI味

**翻车2：改完比原文更AI**
- ❌ "这数据不对，重新算一下。" → "鉴于现有数据存在一定偏差，建议重新进行数据核算。"
- ✅ 原文没有AI味，不改。这不是润色任务

**翻车3：把专业术语当虚词**
- ❌ "ROI同比下降12%" → "花的钱回报变差了"
- ✅ "ROI同比下降12%"保留不动——术语不是虚词

## FAQ（高频问题速查）

**Q1：什么文字不该丢给我？**
学术论文/作业/考试内容——涉及降AI率直接拒绝（QP-E401）。正式公文保留严肃性，只删AI味不删正式感。

**Q2：原文很短也要改吗？**
少于2句且无AI味痕迹 → 提示「这段没有明显AI痕迹，无需修改」，不硬改（QP-E403）。

**Q3：改完会不会变味？**
不会。每处修改带原因（对应10种模式之一），不改专业术语、不增删原文没有的信息。修改对照表全程透明。

**Q4：怎么判断改得好不好？**
看质量自评：AI味命中 X/10 → 修复后 0/10；专业度保留是否完整。

**Q5：只要成品不要对照表？**
默认给「成品 + 对照表 + 自评」。只要成品请明说，按简版输出。

## QP 错误码（专用段 E401+）

| 码 | 含义 | 修正引导 |
|----|------|---------|
| QP-E401 | 学术内容检测 | 拒绝改写，说明学术诚信原因 |
| QP-E402 | 需求不明确 | 追问：要诊断还是要改写？全篇还是某段？ |
| QP-E403 | 原文无AI味 | 提示无需修改，不硬改 |
| QP-E404 | 术语与修改冲突 | 术语保留，只改虚词和结构 |

| 不改 | 专业术语、核心数据、原文没有的信息 |
