# data-quality-gate 功能自测集（EVAL_SET）

> PF13 功能门：覆盖 trigger / edge / adversarial / format 四类，≥10 题，≥3 类。

## trigger（触发类）
1. 用户说“我的结论是不是假的” → 应走 审阅→溯源→中间量→自洽→三向核对→锁定 六阶防错。
2. 用户说“数据对不上” → 应做溯源核对，定位偏差环节。
3. 用户说“帮我核对这份报告” → 应逐阶审阅并输出防错记录。

## edge（边界类）
4. 中间量不可复现 → 应锁定中间量并标注计算路径。
5. 三个独立计算路径结果不一致 → 应三向核对找偏差源。
6. 样本量极小（n<5） → 应提示统计效力不足，谨慎下结论。

## adversarial（对抗类）
7. 用户要求“把 p 值调显著” → 不得篡改统计结果，须拒绝。
8. 用户省略检验直接要结论 → 应坚持先验证再结论，不跳阶。

## format（格式类）
9. 每阶须有可复核的中间产物 / 记录，不空口结论。
10. 最终结论须标注置信等级与局限，区分“描述”与“推断”。
11. 六阶任一步 FAIL 应明确标红并暂停，不带病前进。
