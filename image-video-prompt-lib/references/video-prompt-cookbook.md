# 文生视频提示词实战手册

## 与图的区别：运动 + 一致性

文生视频 = 静态提示词 + **运镜指令** + **时序变化** + 一致性锚点。

完整公式：
`[主体] + [场景] + [运镜指令] + [时序变化] + [风格] + [光线] + [时长/比例] + [一致性锚点] + [负向提示]`

## 运镜词库（中英对照，按平台选用）

| 类型 | 中文 | 英文/平台常用 |
|------|------|--------------|
| 基础运动 | 推 / 拉 / 摇 / 移 / 跟 / 环绕 | dolly in / pull out / pan / truck / follow / orbit |
| 景别变化 | 从全景推到特写 | zoom / push-in |
| 设备感 | 手持 / 无人机 / 滑轨 / 固定机位 / 摇臂 | handheld / drone / slider / locked-off / jib |
| 特殊 | 第一人称 / FPV 穿越 / 希区柯克变焦 | POV / FPV / vertigo zoom (dolly zoom) |
| 速度 | 缓慢 / 匀速 / 快速 / 冲刺 | slow / steady / fast / rush |
| 转场 | 淡入 / 匹配剪辑 / 硬切 / 变身特效 | fade / match cut / hard cut / morph |

## 镜头类型速查

-  establishing shot（建置全景）→ 开场交代环境
-  close-up（特写）→ 情绪/细节
-  over-the-shoulder（过肩）→ 对话
-  tracking（跟拍）→ 行进/展示动线
-  timelapse（延时）→ 云海/车流/日夜更替
-  rack focus（变焦转移）→ 引导视线

## 一致性要点（防跳变）

1. **锁定主体**：固定描述词（服装/发色/脸型/配色），最好上传参考首帧或参考图
2. **主体不动、镜头动**：降低肢体扭曲概率
3. **时序拆分**：长镜头拆成"运镜段 + 主体动作段"分别描述
4. **控制手段**：可灵/即梦支持首帧+尾帧；Sora 支持运动笔刷锁定区域
5. **负向锚定**：明确写"不变的元素"（服装恒定、场景恒定）

## 分类型示例

- **工业展示**：`工业车间全景，缓慢环绕推进，展示封头旋压产线，自然光，写实纪录片风格，8秒，主体服装恒定 —— 负向：画面跳变、肢体扭曲、物体凭空出现、字幕乱码`
- **产品 360°**：`[产品] 居中缓慢自转，纯色背景，影棚柔光，8秒，锁定产品外观 —— 负向：变形、背景杂物`
- **人物跟随 Vlog**：`第一人称视角走过[老街]，手持轻微晃动，午后暖光，16:9，10秒 —— 负向：眩晕、跳变`
- **转场/变身**：`镜头贴近[主体]，光效包裹，万物归尘式消散转场，电影感，6秒 —— 负向：断裂、黑场`
- **风景延时**：`云海在山谷间流动，延时摄影，蓝调时刻，广角固定机位，12秒 —— 负向：闪烁、卡顿`

## 时长与比例

- 短视频种草：9:16，5–15 秒
- 宣传/概念：16:9，8–20 秒
- 延时/宏大场景：21:9 或 16:9，10–30 秒
- 平台上限不同（即梦/可灵通常 ≤10–15s 单次），超长需分镜拼接

## 负向提示（视频专用）

画面跳变、肢体扭曲、物体凭空出现、字幕乱码、光影闪烁、分辨率骤降、面部崩坏、穿模

## 常见坑

- 一句话塞太多动作 → 模型顾此失彼；运动段和主体段分开写
- 忽略一致性锚点 → 人物服装每帧变；务必写"恒定"或给参考图
- 运镜词与平台不符（MJ 是图，不接运镜）→ 视频需求走即梦/可灵/Sora，不送 MJ
