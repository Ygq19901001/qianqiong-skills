# 文生图提示词实战手册

## 通用公式

`[主体] + [动作/状态] + [环境] + [光线] + [风格] + [镜头/画幅] + [负向提示] + [平台参数]`

> 顺序不绝对，但"主体→环境→风格→技术参数"最稳；负向提示放末尾或独立框（看平台）。

## 分类型示例（直接改方括号）

- **写实产品图**：`一只[不锈钢封头]静置在检测台上，侧光勾边，工业摄影风格，85mm 镜头，8k —— 负向：变形、文字、水印`
- **场景氛围**：`黄昏的[封头制造车间]，暖光从天窗洒下，工人巡检，纪实摄影，35mm —— 负向：过曝、畸变`
- **人像写真（胶片）**：`亚洲女性半身肖像，逆光发丝光，富士胶片色调，柔焦，50mm —— 负向：畸变脸、磨皮过度、水印`
- **美食（精致料理）**：`一碗热气腾腾的[拉面]，俯拍 45°，暖光，浅景深，美食摄影 —— 负向：干瘪、塑料感、杂乱背景`
- **风景氛围（晨雾山林）**：`晨雾中的针叶林，丁达尔光，冷色调，广角，风光摄影 —— 负向：死黑、过曝、噪点`
- **插画绘本（儿童）**：`圆润可爱的小熊在采蘑菇，2.5D 厚涂，马卡龙色，扁平构图 —— 负向：恐怖、写实、杂乱线条`
- **学术示意图**：`论文用系统架构图，扁平化矢量风格，深蓝主色 #2C5AA0 + 浅蓝 #D6E4F4，留白充足，圆角矩形 —— 负向：照片感、阴影过重、文字错位`
- **科技感概念图（未来城市）**：`悬浮未来城市夜景，霓虹光带，体积光，赛博朋克，电影感广角 —— 负向：模糊、廉价感`

## 镜头与画幅

| 维度 | 取值 |
|------|------|
| 镜头焦距 | 广角 14–24mm / 标准 35–50mm / 长焦 85–200mm / 微距 100mm |
| 景别 | 远景 / 全景 / 中景 / 近景 / 特写 / 大特写 |
| 画幅 | 横版 16:9 / 竖版 9:16 / 方形 1:1 / 超宽 21:9 |
| 构图 | 三分法 / 中心构图 / 对称 / 引导线 / 框架式 / 俯拍 / 仰拍 / 低角度 |

## 光线词汇

自然光（晨光/夕阳/窗光/丁达尔）、人造光（霓虹/聚光/轮廓光/环闪）、质量（柔光/硬光/体积光/边缘光）、氛围（冷暖对比/低键/高键）。

## 负向提示词模板（按场景挑选）

- **通用**：模糊、畸变、多余肢体、水印、低分辨率、文字错乱、过曝、拼接痕迹、塑料感、丑陋
- **人像**：畸变脸、六指、不对称眼睛、磨皮过度、奇怪牙齿
- **产品/工业**：变形、反光过曝、背景杂乱、比例失调
- **插画/二次元**：写实感、脏线、崩坏、低饱和
- **学术图**：照片质感、重阴影、文字溢出、配色刺眼

## 平台习惯

- **Midjourney v7**：`--ar 16:9 --v 7 --style raw --no 变形,水印`，多概念用 `::` 权重分隔
- **Stable Diffusion / SDXL**：括号 `( )` 提权重 `word:1.2`；Negative prompt 独立框；指定采样器（DPM++ 2M Karras）/步数/CFG
- **即梦 / 可灵 / 可图**：中文自然语言直接写，风格词放句尾，运镜词句中
- **通用技巧**：主体用具体名词而非"好看的"，避免"非常/极其"等空泛词；用逗号分隔而非长句

## 常见坑

- 主体描述太抽象 → 模型自由发挥失控；尽量给"材质+姿态+环境"
- 负向堆 30 个词 → 反而互相抵消；精选 5–10 个最关键的
- 画幅与构图矛盾（既要特写又要全景）→ 取一个主意图
