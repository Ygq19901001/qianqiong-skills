# 分平台参数速查

> 本表收录 Midjourney v7、Stable Diffusion / SDXL、即梦(Jimeng)、可灵(Kling)、可图(Kolor) 的**实际可用参数**。每条均给出「格式 + 示例 + 适用场景」。写法以各平台当前版本为准。

---

## 一、Midjourney v7（文生图 / 图生图）

MJ 用自然语言英文写主体，参数以 `--` 后缀追加。v7 为当前默认版本。

| 参数 | 格式 | 示例 | 适用场景 |
|------|------|------|----------|
| 画幅 | `--ar 宽:高` | `--ar 16:9` / `--ar 9:16` / `--ar 3:2` | 横屏/竖屏/印刷；常用 16:9、9:16、1:1、3:2 |
| 版本 | `--v 7` | `--v 7` | 显式锁定 v7（默认即 v7，可省略） |
| 风格 | `--style raw` | `--style raw` | 关闭 MJ 自动美化、更忠于提示词（产品/写实首选） |
| 风格化 | `--stylize <0-1000>` 或 `-s` | `--s 250` | 值越高越「艺术化」，越低越写实；写实图用 50-250 |
| 混乱度 | `--chaos <0-100>` 或 `-c` | `--chaos 20` | 提高出图多样性；批量找灵感用 30-60，求稳用 0-10 |
| 质量 | `--quality <0.25/0.5/1>` 或 `-q` | `--q 1` | 渲染精细度；海报用 1，草图用 0.5 |
| 权重分隔 | `词::权重` | `red dress::2 blue sky::1` | 提升/压低某元素权重，权重默认 1 |
| 风格参考 | `--sref <图片URL>` | `--sref https://...` | 套用参考图的画风/色彩 |
| 角色参考 | `--cref <图片URL>` | `--cref https://... --cw 100` | 保持同一角色脸/服装；`--cw` 控制角色权重(0-100) |
| 排除 | `--no 词` | `--no text, watermark` | 等价于负向提示，去掉某元素 |
| 种子 | `--seed <整数>` | `--seed 1234` | 复现/微调同一构图 |

**完整示例**
```
a stainless steel pressure vessel on a white studio turntable, side light rim, product photography, 85mm, 8k --ar 3:2 --v 7 --style raw --s 150 --no text, watermark, distortion --seed 42
```
适用：电商产品白底/棚拍，需要稳定还原实物。

**要点**：MJ 不用负向框，用 `--no`；多概念用 `::` 权重分区；`--style raw` 是写实类必加项。

## 二、Stable Diffusion / SDXL（文生图，WebUI/ComfyUI）

SD 系用逗号分隔的标签语法，负向提示独立成框，权重用括号。

| 参数 | 格式 | 示例 | 适用场景 |
|------|------|------|----------|
| 正向提示 | 逗号标签 | `masterpiece, best quality, 1girl, ...` | 核心描述，越靠前权重越高 |
| 负向提示 | Negative prompt 框 | `lowres, bad anatomy, extra fingers, watermark` | 必须单独填写，抑制瑕疵 |
| 提权重 | `(word:1.2)` | `(red hair:1.3)` | 括号一层 +1.1 倍，`word:1.2` 精确加权 |
| 降权重 | `[word]` | `[blurry]` | 压低某标签 |
| LoRA | `<lora:name:权重>` | `<lora:film:0.8>` | 加载风格/角色 LoRA |
| 采样器 | Euler a / DPM++ 2M Karras | 选 `DPM++ 2M Karras` | 写实推荐 DPM++ 2M Karras；动漫可用 Euler a |
| 步数 | Steps 20-40 | `Steps: 30` | SDXL 25-35 足矣，过高无意义 |
| CFG | 7-12（SDXL 5-8） | `CFG: 7` | 越高越贴近提示词，过高易过饱和；SDXL 用 5-8 |
| 尺寸 | SD 512² / SDXL 1024² | `1024x1024` / `1216x832` | 必须匹配基模分辨率，否则畸变 |
| 种子 | Seed | `Seed: 12345` | 复现构图 |

**完整示例（SDXL 写实产品）**
```
Positive: masterpiece, best quality, product photography, stainless steel valve, centered on white background, soft studio light, 85mm, sharp focus, 8k
Negative: lowres, bad anatomy, extra limbs, text, watermark, blurry, distorted, oversaturated
Sampler: DPM++ 2M Karras, Steps: 30, CFG: 6.5, Size: 1024x1024, Seed: 12345
```
适用：需要像素级控制、批量出图、商用素材本地部署。

## 三、即梦 Jimeng（字节，文生图 + 文生视频）

即梦对中文自然语言理解好，**直接写中文句子**，风格词放句尾，运镜词写在描述中。

| 参数 | 格式 | 示例 | 适用场景 |
|------|------|------|----------|
| 运镜 | 中文动作词 | `镜头缓慢推进` / `环绕主体` / `从上方俯拍` | 视频必备，放句中描述 |
| 镜头 | 景别词 | `近景` / `特写` / `中景` / `全景` | 控制画面范围 |
| 时长 | 设定选 5s/10s | 生成时选「10秒」 | 视频长度；当前支持 5s/10s |
| 比例 | 选 16:9 / 9:16 / 1:1 | 选「9:16」 | 竖屏短视频用 9:16 |
| 运动幅度 | 设置项「小/中/大」 | 选「中」 | 控制动作剧烈程度，防抖动 |
| 精细度 | 设置项「高」 | 选「高」 | 提升细节，耗时长 |
| 风格化 | 句尾风格词 | `...，写实纪录片风格` | 风格词统一放句尾 |

**完整示例（视频）**
```
一位身穿白色风衣的模特走在都市街头，镜头从侧后方缓慢跟随，黄昏暖光，车流虚化，电影感，中景 —— 时长10秒，比例16:9，运动幅度中
```
适用：抖音/短视频种草、人物运镜、中文创作流。

**要点**：即梦提示词=「主体+动作+环境+运镜+风格」顺写即可，无需权重符号；图生图可上传首帧做参考。

## 四、可灵 Kling（快手，文生视频 / 图生视频）

可灵强在运动质量与首尾帧控制，支持「运动笔刷」「镜头控制」。

| 参数 | 格式 | 示例 | 适用场景 |
|------|------|------|----------|
| 运镜模式 | 设置项 | 自由 / 横向 / 纵向 / 旋转 / 变焦 | 选「纵向」做上移运镜 |
| 运动笔刷 | 圈选区域+强度 | 在主体上画笔刷「强」 | 让特定物体动、其余静 |
| 时长 | 5s / 10s | 选「10秒」 | 长镜头选 10s |
| 模式 | 标准 / 高品质 | 选「高品质」 | 商用/海报级选高品质 |
| 比例 | 16:9 / 1:1 / 9:16 | 选「16:9」 | 横屏广告用 16:9 |
| 首尾帧 | 上传首帧/尾帧 | 上传首帧图 | 锁定开头画面，防跳变 |
| 负向 | 负向提示框 | `画面跳变, 肢体扭曲` | 独立框填写 |

**完整示例（视频）**
```
主体：一只陶瓷茶杯静置木桌，窗外阳光斜射。运镜：镜头缓慢横向右移，展示桌面与背景绿植。风格：治愈系写实。时长10秒，比例16:9，高品质。
负向：画面跳变, 物体凭空出现, 字幕乱码
```
适用：产品展示、氛围短片、需要高运动质量与首尾帧一致。

**要点**：可灵优先用「图生视频+首帧」保证主体稳定；纯文生用运动笔刷引导动区。

## 五、可图 Kolor（快手，文生图）

可图是中文友好的图像基模，语法接近 SD 但中文标签理解更强，支持风格预设。

| 参数 | 格式 | 示例 | 适用场景 |
|------|------|------|----------|
| 正向 | 中文/英文标签 | `一只橘猫，窗边阳光，水彩风格` | 自然语言或标签均可 |
| 负向 | 负向框 | `畸形, 模糊, 文字, 水印` | 独立框 |
| 风格预设 | 设置项 | 通用 / 胶片 / 动漫 / 插画 / 写实 | 一键切换画风 |
| 尺寸 | 选 1:1 / 3:4 / 4:3 / 16:9 | 选「3:4」 | 竖版 poster 用 3:4 |
| 步数 | 20-30 | 选「30」 | 细节更足 |
| 引导系数 | 5-10 | 选「7」 | 贴合提示程度 |

**完整示例**
```
一只橘猫蜷在窗台阳光下打盹，柔和逆光，日系治愈插画风，干净构图
负向：畸形, 模糊, 多余肢体, 文字, 水印
风格：插画，尺寸 3:4，步数 30，引导 7
```
适用：插画/海报/社媒配图，中文创作、不想写英文标签。

## 平台选择速记

| 需求 | 首选 |
|------|------|
| 艺术创作/氛围海报，英文流畅 | Midjourney v7 |
| 像素级控制/批量/本地商用 | SD / SDXL |
| 中文短视频种草、人物运镜 | 即梦 Jimeng |
| 高质量运动、首尾帧一致视频 | 可灵 Kling |
| 中文插画/海报配图 | 可图 Kolor |
