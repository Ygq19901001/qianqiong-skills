# 图视频生成提示词库

> **用它能解决什么**：文生图/文生视频的提示词不会写？镜头、风格、负向、运镜模板直接出可用 prompt，即梦/可灵/MJ 通用。

> 本库专管**多模态生成提示词**（文生图 / 文生视频）。LLM 系统提示词、对话提示词走 `prompt-engineer`。

## 与 prompt-engineer 的分工

| 技能 | 管什么 |
|------|--------|
| `prompt-engineer`（提示词专家） | 设计 LLM 的 system/user 提示词（文本模型） |
| 本库（图视频生成提示词库） | 设计给图像/视频生成模型的提示词（扩散模型、视频模型）——镜头、风格、负向提示、运镜 |

## 核心结构（图/视频通用）

1. **主体**(subject)：谁/什么，细节描述
2. **环境/场景**(scene)：光线、地点、氛围
3. **风格**(style)：写实/插画/3D/胶片…
4. **技术参数**(params)：画幅、镜头、分辨率
5. **负向提示**(negative)：不想要的元素
6. **一致性锚点**(consistency)：视频需锁定角色/场景 seed

## 公式速查

**文生图通用公式**

```
[主体] + [动作/状态] + [环境] + [光线] + [风格] + [镜头/画幅] + [负向提示] + [平台参数]
```

**文生视频通用公式**

```
[主体] + [场景] + [运镜指令] + [时序变化] + [风格] + [光线] + [时长/比例] + [一致性锚点] + [负向提示]
```

> 视频比图多三样：**运镜指令**（推/拉/摇/移/跟/环绕）、**时序变化**（动作如何演进）、**一致性锚点**（锁 seed / 首帧 / 固定服装描述防跳变）。

## 平台选择指引

| 需求 | 首选平台 | 关键写法 |
|------|---------|---------|
| 艺术创作 / 氛围海报，英文流畅 | Midjourney v7 | 英文自然语言 + `--ar` + `--v 7` + `--style raw` + `--no` 负向 |
| 像素级控制 / 批量 / 本地商用 | SD / SDXL | 逗号标签 + `( )` 权重 + 独立 Negative 框 + 采样器/步数/CFG |
| 中文短视频种草、人物运镜 | 即梦 Jimeng | 中文顺写 + 句中运镜词 + 风格词放句尾 |
| 高运动质量、首尾帧一致视频 | 可灵 Kling | 运镜模式/运动笔刷 + 首帧上传 + 负向框 |
| 中文插画 / 海报配图 | 可图 Kolor | 中文标签 + 风格预设 + 负向框 |

> 各平台**具体参数格式与示例**见 [platform-params.md](references/platform-params.md)，不要凭记忆拼参数。

## 质量红线

- 不生成侵权或恶意复刻真人肖像的提示词
- 负向提示不得用于绕过模型安全策略
- 商用前确认素材/风格版权
