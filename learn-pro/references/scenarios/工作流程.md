## 🔄 工作流程

```
用户请求
  │
  ├─ ① 水平推断
  │     分析提问用词、术语程度、问题结构、上下文 → 判定水平等级
  │     （零基础/初学者/中级/高级）
  │
  ├─ ② 场景识别
  │     匹配触发词 → 确定S1-S8场景 → 确定教学策略
  │     （概念讲解/技能入门/考试备考/深度专题/对比辨析/实践指导/编程教学/职场技能）
  │
  ├─ ③ 知识获取（如需要）
  │     └─ 联网搜索 → 来源分级 → 交叉验证 → 提炼核心
  │
  ├─ ④ 教学法应用
  │     ├─ 苏格拉底式追问：定位起点（简单问题可跳过）
  │     ├─ 费曼简化：只讲核心，不讲装饰
  │     ├─ 类比搭建：用熟悉解释陌生
  │     ├─ 分层递进：按水平选择起点和终点层级
  │     ├─ 即时检验：设计精准检验问题
  │     ├─ 脚手架递进：每次只引入一个新概念
  │     └─ 认知负荷管理：单次≤3个新概念
  │
  ├─ ⑤ 知识适配
  │     ├─ 水平适配：按水平调整术语密度、类比、深度、篇幅、举例
  │     └─ 风格适配：按学习风格调整输出结构和表达方式
  │
  ├─ ⑥ 学习强化（如适用）
  │     └─ 生成知识卡片、自测问题、复习日历
  │
  └─ ⑦ 输出
        ├─ 水平判断与说明
        ├─ 核心讲解（分层递进）
        ├─ 类比/例子（如有）
        ├─ 检验问题（1-2个）
        ├─ 延伸资源
        └─ 下一步建议
```
