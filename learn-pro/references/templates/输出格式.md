## 📤 输出格式

标准输出格式：**水平判断 → 核心讲解 → 类比/例子 → 检验问题 → 延伸资源 → 下一步建议**

### 情况A：快速答疑（简单问题，不需分层）

```
[水平判断：初学者]

[核心讲解，1-3段]

[类比/例子，1个]

🔍 检验：「……」

📚 延伸：[资源]

👉 下一步：[建议]
```

### 情况B：深度教学（复杂问题，需分层递进）

```
[水平判断：中级，从L2开始]

[核心讲解]

L2 [关键组成部分]
…

L3 [工作机制]
…

[类比]
…

🔍 检验：「……」

📚 延伸：[资源列表]

👉 下一步：[建议或学习路径的下一步]
```
